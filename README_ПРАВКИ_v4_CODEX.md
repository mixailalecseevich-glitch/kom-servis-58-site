# КОМ СЕРВИС 58 — v4: упрощённые формы и электронная почта

## Изменения
- Контактный email на всех страницах сайта: info@komservice58.ru (ссылки mailto также обновлены).
- Поле «Детали (необязательно)» удалено из обычных и модальных форм.
- Формы: услуга, имя, телефон, обязательное согласие. Скрытый антиспам-поле `website` сохранено.
- На каждой странице конкретной услуги услуга автоматически выбрана в обычной форме и модальном окне. На главной и общих/служебных страницах выбор оставлен доступным.
- API `/api/lead.php` дополнен дополнительными названиями услуг, включая илосос, септики и засоры. Комментарий в API остался необязательным для обратной совместимости, но посетителю не показывается.
- Номера сохранены: +7 (927) 375-27-57 — биотуалеты и ассенизация (этот номер привязан к MAX), +7 (937) 444-97-77 — ковры, химчистка, клининг.

## Важно перед публикацией
- GitHub Pages не выполняет PHP. Формы на статической версии не отправляют заявки; скрипт честно отключает кнопку при недоступном API. Для реальной отправки нужен PHP-хостинг в РФ или отдельный backend.
- Секреты MAX не записывать в GitHub! Настроить `private/config.php` только на сервере, после подключения бота и подтверждения размещения данных в РФ.
- Проверить, что `info@komservice58.ru` реально создан и принимает почту: сайт меняет контактную ссылку, но не создаёт ящик.
- Проверить юридические документы и фактические адреса/реквизиты перед запуском рекламы.
- В скрипте `assets/main.js` предзаполнение не отключает возможность изменить услугу при необходимости.

## Проверки
1. Открыть `/himchistka-mebeli/`: в нижней форме и в «Рассчитать стоимость» сразу «Химчистка мебели».
2. Открыть `/biotualety/`: аналогично «Биотуалеты».
3. Открыть `/gryazezashchitnye-kovry/`: «Грязезащитные ковры».
4. Открыть `/klining/`: «Клининг».
5. Проверить страницы илососа, септиков, засоров и страницу бизнеса.
6. На главной странице услугу выбирает посетитель.
7. Во всех формах проверить имя, телефон, чекбокс согласия, отсутствие поля «Детали».
8. Проверить ссылки `mailto:info@komservice58.ru` и оба телефонных направления.
9. На сервере с работающим PHP и настройкой MAX протестировать доставку заявки в бот (не на GitHub Pages).
