## ВАЖНО: GitHub Pages и формы
GitHub Pages обслуживает только статические файлы. PHP API (`/api/status.php`, `/api/lead.php`) и запись в SQLite на GitHub Pages **не выполняются**. Кнопки звонков работают, но отправка форм будет отключена и посетителям предложат звонить. Не обещайте приём заявок в MAX до установки PHP на сервере РФ или до разработки отдельного серверного обработчика. Не выкладывайте секретные токены MAX в репозиторий.

## Codex
1. Разархивировать проект, загрузить на GitHub в отдельный репозиторий (не подменять сразу действующий сайт).
2. Для GitHub Pages проверить абсолютные пути `/assets/...` и `/.../` — для репозитория проекта могут потребоваться относительные пути или настройка базового пути. Для собственного домена с корнем веб-сервера они работают.
3. Не менять DNS `bioservice58.ru`, пока не подготовлен подходящий хостинг с PHP и протестирована доставка заявок.
4. Проверить все кнопки звонков на мобильных устройствах; на общей странице выбрать нужное направление.
5. Проверить политику ПД, реквизиты, COOKIE, адреса и юридическую информацию с владельцем до публикации.
6. После выдачи публичного MAX URL настроить `private/config.php` на PHP-хостинге РФ, установить Web API и тестовую отправку.
7. Не подключать Яндекс Метрику без согласования обработки данных и настройки cookie-согласий.
